# Gweth's Corner

Welcome to my personal website!

This is a small project I built while learning HTML and CSS. It is a place to introduce myself, share my interests, and document my journey into programming.

The website introduces who I am, what I enjoy, and what I'm working towards. I wanted to create something personal while practising the fundamental knowledge gained of web development.

## Built With

- HTML(hyper text markup language)
- CSS(cascading style sheet)

- Styling text, headings, and links with CSS

- Connecting an HTML file to a CSS stylesheet
